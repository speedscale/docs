Open PowerShell and run:

```powershell
irm https://downloads.speedscale.com/proxymock/install-proxymock.ps1 | iex
```

The installer needs no administrator rights. It puts `proxymock.exe` in `%USERPROFILE%\.speedscale`, adds that folder to your user Path and runs `proxymock init`. When init offers to trust the proxymock certificate, confirm the **Security Warning** dialog so clients that use the Windows certificate store, such as .NET, accept proxymock for HTTPS. Run the same command again to upgrade.

To install a specific version:

```powershell
& ([scriptblock]::Create((irm https://downloads.speedscale.com/proxymock/install-proxymock.ps1))) v2.5.1476
```

<details>
<summary>Install without the script</summary>

Download `proxymock.exe` into a Speedscale folder:

```powershell
mkdir -Force $env:USERPROFILE\.speedscale
curl.exe -L "https://downloads.speedscale.com/proxymock/proxymock.exe" -o $env:USERPROFILE\.speedscale\proxymock.exe
```

Add the folder to your user Path:

```powershell
$dir = "$env:USERPROFILE\.speedscale"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if (($userPath -split ';') -notcontains $dir) {
  [Environment]::SetEnvironmentVariable("Path", (($userPath.TrimEnd(';') + ";$dir").TrimStart(';')), "User")
}
```

Restart PowerShell and run `proxymock init`. If you skip the certificate prompt or set up a headless machine, follow the [Windows certificate store](/proxymock/getting-started/language-reference#windows-tls-trust) steps.

</details>

proxymock also runs inside [WSL](https://learn.microsoft.com/en-us/windows/wsl/). Use the Linux tab there.

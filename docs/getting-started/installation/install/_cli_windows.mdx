Open PowerShell and run:

```powershell
irm https://downloads.speedscale.com/speedctl/install-speedctl.ps1 | iex
```

The installer needs no administrator rights. It puts `speedctl.exe` in `%USERPROFILE%\.speedscale`, adds that folder to your user Path and runs `speedctl init`. Run the same command again to upgrade.

To install a specific version:

```powershell
& ([scriptblock]::Create((irm https://downloads.speedscale.com/speedctl/install-speedctl.ps1))) v2.5.1476
```

<details>
<summary>Install without the script</summary>

Download `speedctl.exe` into a Speedscale folder:

```powershell
mkdir -Force $env:USERPROFILE\.speedscale
curl.exe -L "https://downloads.speedscale.com/speedctl/speedctl.exe" -o $env:USERPROFILE\.speedscale\speedctl.exe
```

Add the folder to your user Path:

```powershell
$dir = "$env:USERPROFILE\.speedscale"
$userPath = [string][Environment]::GetEnvironmentVariable("Path", "User")
if (($userPath -split ';') -notcontains $dir) {
  [Environment]::SetEnvironmentVariable("Path", (($userPath.TrimEnd(';') + ";$dir").TrimStart(';')), "User")
}
```

Restart PowerShell and run `speedctl init`.

</details>

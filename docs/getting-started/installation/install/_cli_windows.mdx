Open PowerShell, create a Speedscale directory and download `speedctl` into it:

```powershell
mkdir -Force $env:USERPROFILE\.speedscale
curl.exe -L "https://downloads.speedscale.com/speedctl/speedctl.exe" -o $env:USERPROFILE\.speedscale\speedctl.exe
```

Add the directory to your user Path so you can run `speedctl` from any folder. This does not need administrator rights.

```powershell
$dir = "$env:USERPROFILE\.speedscale"
$userPath = [string][Environment]::GetEnvironmentVariable("Path", "User")
if (($userPath -split ';') -notcontains $dir) {
  [Environment]::SetEnvironmentVariable("Path", (($userPath.TrimEnd(';') + ";$dir").TrimStart(';')), "User")
}
```

Restart PowerShell, then run `speedctl --help` to confirm it is on your Path.
